The pi-qbot Dockerfile writes `/root/.pi/agent/settings.json` with `defaultTools: ["+codemode"]` (merged/uniqued with existing entries), so host and per-chat SDK sessions inherit codemode while retaining normal tools. The image also installs `python-is-python3`, `python3-pil`, and `ffmpeg` for agent media work. Dockerfile/settings changes require `docker compose up -d --build`, not just a restart.
