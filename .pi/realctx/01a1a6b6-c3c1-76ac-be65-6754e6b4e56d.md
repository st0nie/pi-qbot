In `pi-qbot` (official QQ Bot API v2 bridge), pat/poke support (`qq_pat`, `detectPat`, and `skills/qq-pat`) was removed after live testing confirmed the gateway does not push poke/pat events.
- Inbound `quoteMsgId` is matched against `this.sent` (`(quote @me: ...)`) and `this.refs` (`(quote #N: ...)`), with a fast 600 ms debounce when quoted.
- Outbound `qq_send` supports `reply_to` (`#N` message number; anchors passive `msg_id` to `#N` if within `PASSIVE_WINDOW_MS` and sends `message_reference`) and `at` (nickname, `#N`, or an array of them).
- Two bundled skills in `skills/` (`qq-quote-reply`, `qq-mention`) are loaded into every per-chat session via `additionalSkillPaths: builtinSkillPaths()` on `DefaultResourceLoader`.
